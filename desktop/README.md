# Stock Portfolio for Windows

运行 `Stock-Portfolio-Setup-1.4.2-x64.exe` 后，从 Windows 开始菜单打开 **Stock Portfolio**。旧版 1.0.x 无法打开升级后的加密账本。[已发布的 Windows 安装程序](https://github.com/JasonCodeMaker/Stack-Portfolio/releases)

从 1.4.0 升级后，在「导入与对账」同步 IBKR。预览会列出已有流水可补充的券商凭据和带日期的结单报价。总览和持仓把剩余股份的含费买入成本、市值和账面盈亏按同一估值汇率折成澳元。逐笔成交的报表汇率可在持仓的关联流水中查看。总览单独列出券商净值与逐项估值的差额。

## 接手现有账本

首页可预览本机 Wealthfolio 账户、流水、行情和设置的数量，或选择未加密的 SQLite 账本备份。确认迁入后，应用在当前 Windows 用户的 `%APPDATA%\Stack Portfolio\portfolio.sqlite` 中独立保存账本。保留原记录编号、手工更正、同步去重记录、配置目标、ETF 数据及原始估值。加密的 Wealthfolio 备份可先在 Wealthfolio 中导出为未加密的本地数据库。

在 **数据与设置 → 连接与更新** 重新授权 IBKR Flex、Webull Australia 和所用的数据源。IBKR 按需读取最近 365 天，Webull 读取最近六个月。更早的记录可从文件导入。现金流水未覆盖时，可用同日月结单核对并补录。**数据与设置 → 账本与备份** 提供本地备份和恢复。恢复已有正式账本时，会先保留一份恢复前的副本。

## 加密、备份与恢复

首次启动 1.1 后，应用会加密正式账本、示例账本及应用数据目录内的旧版 SQLite 账本备份。升级会先读取已提交的数据库日志，再校验加密副本，最后原子替换文件。平时使用 SQLCipher 按页读写。随机生成的 256 位密钥由当前 Windows 用户保护，券商 token 和行情密钥另有一层 Windows 加密。

在 **数据与设置 → 账本与备份 → 备份账本** 创建 `.spbackup` 文件。为备份设置独立密码，将密码保存在密码管理器。重装系统或换电脑后，可在欢迎页选择 **从账本备份恢复**。忘记备份密码且已失去原账本访问权限时，无法恢复这份密码备份。跨 Windows 账户恢复后，需要重新授权券商和行情连接。

**加密旧备份** 可把其他目录中的旧版明文备份、或本机的自动恢复副本，直接转成密码备份。转换保留来源文件。应用只会自动升级自己数据目录中的账本，其他位置的原始文件仍需单独保管。每次覆盖已有账本前，应用会在数据目录保存一份经校验的本机加密副本。

若 Windows 配置损坏导致自动解锁失败，请保留整个 `%APPDATA%\Stack Portfolio` 目录。退出应用后可将目录改名留存，重新启动应用，再从独立的密码备份恢复。

## 试用示例组合

**总览** 先显示估值日的总资产、持仓账面盈亏和全部证券。点证券可查看各账户的股数。缺成本的证券仍计入市值，盈亏旁会写明已计入几只。下方的期间盈亏可打开同一账户和日期范围的复盘。**持仓** 按账户用澳元并列展示市值、成本和盈亏，现金单列。点证券可对照原币现价和买入均价。

持仓现价显示估值当日或之前的最近行情及其来源，缺少行情会显示“待报价”。买卖成交用于计算成本、数量和现金。IBKR Flex 同时提供交易日和报表时间时，流水按券商交易日入账。

点击左下角的账本名称可切换正式账本与示例账本。示例组合有一份 Webull 成交文件和一份月结单。在 **导入与对账 → 同步券商** 分别预览两家券商，确认 Webull 的一笔买入。打开示例月结单，填入期末余额和持仓，比较差异，再按凭证补录 A$1,000 入金并完成对账。总览会显示 A$128,400 总资产和 A$3,200 期间投资盈亏。再次同步时，Webull 会显示「没有新变化」。

**配置分析 → 我买的证券** 列出直接持有的证券和现金占比。点开 ETF 可查看成分。**实际投了哪些公司** 合并直接持股与通过基金持有的金额，可按行业展开其余公司。**配置目标** 可只为选中的证券设置比例，单账户与全部账户各自保存目标。

**手工补一条** 可按凭据补买卖、某日的持股数量或资金收支。以后补回成交，应用会核对股数并列出差额。在持仓行点 **补报价** 或 **补成本**，可直接补充该账户和证券所缺的数据。

## 策略复盘

从左侧打开 **策略复盘**，选择一个或多个账户。页面顶部直接给出组合的时间加权收益率，以及相对标普 500 和纳斯达克 100 跑赢或跑输多少个百分点。正式账本会自动补齐当前区间的指数总回报、澳元汇率和持仓日收盘价，数据来自 Yahoo Finance 与 FRED 的公开接口，无需 API Key，请求只包含证券代码和日期。可在 **数据与设置 → 连接与更新 → 行情自动更新** 关闭或手动更新。行情缓存和复盘笔记随本地加密账本一起备份。

在图中悬停读取每日数值，点选一天查看持仓、现金占比和流水，拖选一段时间可将三条曲线重新归零。点图例可隐藏曲线，只留一个指数时会标出领先与落后的区域。切换 **收益差** 查看领先幅度的变化。**这段时间的盈亏来自哪里** 按澳元贡献列出区间内持有和已卖清的证券，计入对应的分红及费用。现金利息和待归属收支单列，可点开查看原始流水。当日收盘价尚未取得时，结果截至最近一个可估值的收盘日。公开来源没有的收盘价可用已连接的 Twelve Data 补齐或手工补录，还待补充的日期会显示在 **行情与计算口径**。保存笔记后，点击 **重开区间** 可核对记录时的指标与当前重算值。

## 本地构建

从本目录执行 `npm ci --ignore-scripts`，使用 SQLite 依赖随包提供的预编译二进制，再执行 `npm start`。开发环境需要 Node.js 22.15 或更高版本。运行 `npm run typecheck` 检查配置分析和券商模块的类型，运行 `npm test` 验证账本、迁移、对账、复盘、配置分析和券商同步。测试构建完成后，运行 `node tests/windows-smoke.cjs` 检查 Windows 界面流程。运行 `npm run dist` 会在 `../release/desktop/` 生成 Windows x64 安装包。安装后的软件自带运行环境。
