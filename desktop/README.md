# Stock Portfolio for Windows

运行 `Stock-Portfolio-Setup-1.4.7-x64.exe` 后，从 Windows 开始菜单打开 **Stock Portfolio**。旧版 1.0.x 无法打开升级后的加密账本。[已发布的 Windows 安装程序](https://github.com/JasonCodeMaker/Stock-Portfolio/releases)

窗口按可用空间自动缩放，并在 16:9 和 21:9 布局之间切换。在 **设置 → 界面缩放** 可以设为 85% 至 130%，每次调整 5%。也可以用 `Ctrl+=` 或 `Ctrl++` 放大，`Ctrl+-` 缩小，`Ctrl+0` 恢复 100%。缩放偏好随应用保存，切换账本后也会保留。

从 1.4.0 升级后，在「导入与对账」同步 IBKR。预览会列出已有流水可补充的券商凭据和带日期的结单报价。持仓把剩余股份的含费买入成本、市值和未实现盈亏按同一估值汇率折成澳元。逐笔成交的报表汇率可在持仓明细的关联流水中查看。可在「和券商结单核对」比较同日现金、持仓和净值。

## 接手现有账本

首页可预览本机 Wealthfolio 账户、流水、行情和设置的数量，或选择未加密的 SQLite 账本备份。确认迁入后，应用在当前 Windows 用户的 `%APPDATA%\Stack Portfolio\portfolio.sqlite` 中独立保存账本。保留原记录编号、手工更正、同步去重记录、配置目标、ETF 数据及原始估值。加密的 Wealthfolio 备份可先在 Wealthfolio 中导出为未加密的本地数据库。

在 **设置 → 券商连接** 重新授权 IBKR Flex 和 Webull Australia。IBKR 按需读取最近 365 天，Webull 读取最近六个月。更早的记录可从文件导入。现金流水未覆盖时，可用同日月结单核对并补录。**设置 → 账本** 提供本地备份和恢复。恢复已有正式账本时，会先保留一份恢复前的副本。

## 加密、备份与恢复

首次启动 1.1 后，应用会加密正式账本、示例账本及应用数据目录内的旧版 SQLite 账本备份。升级会先读取已提交的数据库日志，再校验加密副本，最后原子替换文件。平时使用 SQLCipher 按页读写。随机生成的 256 位密钥由当前 Windows 用户保护，券商 token另有一层 Windows 加密。

在 **设置 → 账本 → 备份账本** 创建 `.spbackup` 文件。为备份设置独立密码，将密码保存在密码管理器。重装系统或换电脑后，可在欢迎页选择 **从账本备份恢复**。忘记备份密码且已失去原账本访问权限时，无法恢复这份密码备份。跨 Windows 账户恢复后，需要重新授权券商连接。

**加密旧备份** 可把其他目录中的旧版明文备份、或本机的自动恢复副本，直接转成密码备份。转换保留来源文件。应用只会自动升级自己数据目录中的账本，其他位置的原始文件仍需单独保管。每次覆盖已有账本前，应用会在数据目录保存一份经校验的本机加密副本。

若 Windows 配置损坏导致自动解锁失败，请保留整个 `%APPDATA%\Stack Portfolio` 目录。退出应用后可将目录改名留存，重新启动应用，再从独立的密码备份恢复。

正式账本的当前总览按布里斯班时间显示各市场最近收盘。账户的最近收盘变动按当前持仓和现金计算，分列股价涨跌与日汇率折算影响。历史估值和收益复盘使用所选期间的完整收盘数据。

## 试用示例组合

**总览** 右上角的布局选择在账户和日期旁。默认使用「经典总览」。选择「日常查账」可将资产、走势和持仓分组查看，应用会记住上次选择。两种布局共用左上方的期间选择器。

**总览** 显示总资产、当日变动、期间投资盈亏、时间加权收益率和期间净投入。点前 5 大持仓中的代码，可跳到 **持仓** 查看各账户股数。持仓按账户显示证券市值、成本、盈亏和现金。点证券可对照原币现价和买入均价。账户范围和估值日在四个分析页之间共用，总览和收益复盘共用所选期间。

持仓现价显示估值当日或之前的最近行情及其来源，缺少行情会显示“待报价”。买卖成交用于计算成本、数量和现金。IBKR Flex 同时提供交易日和报表时间时，流水按券商交易日入账。

点击左下角的账本名称可切换正式账本与示例账本。示例组合有一份 Webull 成交文件和一份月结单。在 **导入与对账 → 同步券商** 分别预览两家券商，确认 Webull 的一笔买入。打开示例月结单，填入期末余额和持仓，比较差异，再按凭证补录 A$1,000 入金并完成对账。总览会显示 A$128,400 总资产和 A$3,200 期间投资盈亏。再次同步时，Webull 会显示「没有新变化」。

**配置分析** 的公司敞口方框图合并直接持股和经 ETF 持有的金额。点公司可查看来源，点 ETF 的 **基金成分** 可查看成分。**设置目标** 接受每只 ETF、个股合计和现金的占比，合计须为 100%，目标随所选账户范围保存。

**手工补一条** 可按凭据补买卖、某日的持股数量或资金收支。以后补回成交，应用会核对股数并列出差额。在证券明细中点 **补报价** 或 **补成本**，可补充该账户和证券的数据。

## 收益复盘

从左侧打开 **收益复盘**，选择账户范围和期间。结论卡显示组合的时间加权收益率、相对所选指数的收益差、最大回撤和最长跑输区间。正式账本会自动补齐当前区间的指数总回报、澳元汇率和持仓日收盘价，数据来自 Yahoo Finance 与 FRED 的公开接口，无需 API Key，请求只包含证券代码和日期。可在 **设置 → 券商连接 → 行情自动更新** 关闭或手动更新。行情缓存和复盘笔记随本地加密账本一起备份。

在图中悬停读取每日数值，点选一天查看持仓、现金占比和流水。拖选可按新期间重新计算。切换 **收益差** 看相对所选基准的变化，期间达到三个月时可切换 **回撤**。**持仓贡献** 按澳元贡献列出期间持有和已卖清的证券，计入对应的分红及费用。现金利息和待归属收支单列，可点开查看原始流水。可在 **数据来源与计算方法** 查看行情覆盖。保存笔记后，点击 **重开区间** 可核对记录时的指标与当前重算值。

## 本地构建

从本目录执行 `npm ci --ignore-scripts`，使用 SQLite 依赖随包提供的预编译二进制，再执行 `npm start`。开发环境需要 Node.js 22.15 或更高版本。运行 `npm run typecheck` 检查类型，运行 `npm test` 构建并验证账本及业务逻辑。构建后运行 `node tests/windows-smoke.cjs` 检查 Windows 界面流程。可加 `--screenshots .testing/spec21/app` 输出截图。运行 `npm run dist` 会在 `../release/desktop/` 生成 Windows x64 安装包。安装后的软件自带运行环境。[验收场景与截图说明](../docs/investment-dashboard-validation.md)
