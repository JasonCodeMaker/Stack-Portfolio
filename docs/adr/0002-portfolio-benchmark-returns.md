# 实盘组合与指数按澳元总回报比较

下文关于独立展示跑输时段及持仓和交易记录的决定已由[区间持仓贡献复盘](0003-portfolio-review-contributions.md)修订。

下文关于区间中段缺口暂停显示指标的决定已由[设计规格 §5.1](../investment-dashboard-design.md#51-数据缺口)修订：缺报价或汇率时沿用当日或之前最近一个已知值，不再暂停指标。

复盘关注所选账户的投资决策。组合合并持仓和现金，采用澳元计价的时间加权收益率，剔除外部资金和证券转入转出的影响，保留现金配置、实际分红和交易费用对收益的影响。

标普 500 和纳斯达克 100 是两个同等地位的基准。两者均采用分红再投资的总回报，按同期汇率折算为澳元，使组合和指数承受的汇率影响在同一币种下可比。

框选日期后，三条累计收益曲线都以该区间起点为零。起点当日组合还不能完整估值时，三条曲线改从区间内首个可估值的收盘日起算，并标明该日。复盘同时展示组合相对每个指数的收益差、三者各自的区间最大回撤，以及组合在同期的持仓和交易记录。

收益差和最大回撤按每日收盘估值计算。每个基准分别标记组合从落后到追平的时段；领先优势缩小时，收益差曲线也反映其变化。选中某日可查看当日持仓、现金占比和交易。

比较保留各基准可核实的历史，并标明各自的数据起点。三者同场比较可切换到共同起点。组合缺少关键报价或汇率时标明缺口，暂停显示依赖缺口的指标。区间末尾的收盘价、汇率或指数点位尚未取得时，收益和收益差截至最近一个可估值的收盘日并注明日期，组合与指数在双方都可计量的最近收盘日比较；区间中段有缺口时，仍暂停显示最大回撤。

区间笔记保存投资者的判断、所选账户、起止日期和参照指数，供日后重新打开该段行情。

日估值将入金视为日初到账、出金视为日末划出。每个指数只采用自身的总回报指数点位，并保留序列来源与覆盖日期。笔记冻结保存时看到的各项指标，重开时另行计算同一范围的当前结果，以便追溯历史修订。

复盘依赖每日数据才可用，因此持仓日收盘价、美元兑澳元汇率和两条指数的点位取自无需密钥的公开来源，在打开应用和进入复盘时自动补齐，投资者可在设置中关闭。请求只包含证券代码和日期。收盘价须与所持上市地点、币种一致才入账；已保存的收盘价不被改写，来源在拆股后重述的历史价格不入账。
