# 复盘区分指数收益差与实盘持仓贡献

投资者复盘时要判断同期领先或落后指数多少，也要知道自己的哪些持仓带来收益或拖累。复盘沿用[澳元总回报比较口径](0002-portfolio-benchmark-returns.md)，用所选区间的证券贡献替代独立的「跑输时段」和「持仓和交易复盘」区块。证券贡献解释实盘自身的投资结果，解释相对指数的差距还需要相应的基准成分及权重等证据。

贡献按区间内各证券带来的澳元盈亏排序，包括期间已经卖清的证券。区间开始前已经持有的证券从区间起点估值算起，便于将更早积累的盈亏归入相应期间。

证券贡献纳入有凭据归属该证券的分红和交易费用。账户现金利息等独立收支单列，尚无归属凭据的收支保留为「待归属」，以便从组合盈亏追溯到原始流水。
