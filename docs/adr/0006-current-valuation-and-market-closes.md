# 当前估值采用最新行情，各市场独立确认收盘价

当前估值基于本地账本的持仓和现金，用同一批可用股价和汇率折算为澳元，供总览、持仓和配置共用。Electron 主进程以只读方式调用已配置且用途获准的行情源，分别记录证券上市地、币种、交易时段、源时间和延迟。优先使用经过验证的来源，切换来源时仍保留报价时点及状态。缓存中允许保留最后有效报价，界面明确标注旧报价，缺少有效价格或汇率时展示可估值小计。

各交易所按本地日历独立确认正式收盘，收到 ASX 收盘价后即更新澳股持仓。当前估值和正式日收盘分别使用最新报价缓存和日估值数据，避免盘前、盘后或实时汇率覆盖可对账的收盘记录。历史估值和复盘继续采用 [ADR 0002](0002-portfolio-benchmark-returns.md) 的日收盘口径，组合收盘变动使用全组合可估值的共同基准日。持仓页面显示各证券相对本市场前收盘的涨跌，组合收盘贡献带自己的日期。

汇率折算影响在当前持仓的原币市值和现金余额固定时，用当前汇率和最近一次完整收盘估值所用汇率分别折算，取两者的澳元差额。所选账户共用同一汇率对和基准，账户影响可以加总。这个口径回答当前金额因折算改变了多少，历史复盘的汇率归因使用期间投资盈亏口径。
