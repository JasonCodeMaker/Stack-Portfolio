# 盈亏构成五项恒等于期间投资盈亏，今日变动采用净值口径

投资者要在总览和复盘看到期间投资盈亏由哪几部分构成，也要看到今天变了多少。两者沿用[澳元总回报比较口径](0002-portfolio-benchmark-returns.md)和[区间持仓贡献](0003-portfolio-review-contributions.md)，不修订这两份记录。选定的口径以「各数字能互相加总」为先，代价是与券商报表逐笔对不上。

## 盈亏构成

期间投资盈亏拆成五项：未实现变动、已实现、分红与利息、费用、汇率。五项之和恒等于期间投资盈亏，总览与复盘在同一期间下数字一致。

- **已实现**按平均成本法在交易币种内计算，再按卖出日汇率折成澳元。IBKR 默认用 FIFO，两者逐笔不同。没有采用各次买入日汇率的澳元历史成本，因为它会让同一只证券卖出前后的盈亏口径跳变。
- **未实现变动**是期末未实现盈亏减期初未实现盈亏，各按当日汇率折算。它与已实现相加等于区间持仓贡献中的价差部分：40 澳元买入、期初市值 100、期内 110 卖清，已实现 +70，未实现变动 −60，贡献 +10。
- **费用**列出全部费用：交易佣金、换汇佣金、账户费用和交易税。构成内的已实现与未实现变动因此按不含交易费用的价差计算，避免同一笔费用算两次。持仓页的成本与盈亏仍含费用，术语表的成本定义不变；「全部」期间下，构成里的已实现与持仓页的累计已实现相差交易费用。
- **分红与利息**取税后净额，按到账日入账并按到账日汇率折算。现金利息并入此项，借款利息记为负数。没有按除息日入账，因为应用没有应计数据；除息日到到账日之间的日收益会与 IBKR 略有出入。
- **汇率**是外币持仓本金和外币现金因汇率变动产生的澳元盈亏，取期间投资盈亏减去其余四项的余数。余数法保证五项恒等，价差折算带来的细小差额也落在这一项。

持仓页每行的累计已实现盈亏和累计分红从该账户有记录起算，含期初余额带入的持仓。没有成本凭据的转入证券不计已实现盈亏。

## 今日变动

今日变动是一日的期间投资盈亏：最近一个全组合可估值的收盘日估值，减前一个可估值收盘日估值，再减当日净外部资金流，以澳元计并标注日期。百分比即当日的时间加权收益。组合与账户两层都用这个口径，逐日相加等于期间投资盈亏。

它包含汇率、分红、利息和费用，因此与券商屏幕上按「现价减前收盘价乘股数」算出的 Daily P&L 不同。没有采用券商口径，因为它漏掉汇率和现金，无法与期间投资盈亏对账。

证券行的金额用同一净值口径，可加总到组合今日变动；百分比改用交易币种内的价格涨跌幅，回答「这只证券今天涨了多少」。同一行的金额与百分比因此不属于同一口径。

## 不做的事

资金加权收益率不提供。它不能与指数的时间加权收益率相比，与时间加权收益率并列又需要解释两个百分比为何不同。
