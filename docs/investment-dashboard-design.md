# Stock Portfolio 设计规格

Stock Portfolio 是一款独立运行的个人投资看板，单用户 Windows 桌面应用（Electron + React，界面中文）。它用本机 SQLite 账本，以 AUD 汇总 IBKR 和 Webull Australia 账户。导入、估值和看板都由应用自行处理，离线可查看已保存的数据。

**定位**：辅助看板。用户不必打开券商软件，就能看清所有账户的投资状态和盈亏。所有数字由应用替用户算好。

术语以 [`GLOSSARY.md`](../GLOSSARY.md) 为准，计算口径以 [`docs/adr/`](adr/) 为准。本文标「待定」的事项尚未决定。

## 1. 设计系统

采用 Apple HIG 的原则和视觉语言，保留 Windows 窗口外观。浅色加深色，跟随系统。

**基调**：绿色主题，绿调中性色，描边面板，无阴影。总览的「总资产」用品牌绿实底主卡。浅色侧栏。

| 强调上的文字 | `#FFFFFF` | `#06140E` |

- 主卡内的涨跌不着色，用主卡文字色加 ▲▼ 和正负号。

### 1.2 图表序列色

固定顺序，不循环。第 1 位固定给「我的组合／总资产」。红色不进序列，留给亏损。

| 6 | `#e87ba4` | `#d55181` |

浅色下第 5、6 位对底色不足 3:1，用到时必须直接标注或提供表格视图。

### 1.3 字体与字阶

Segoe UI Variable（20px 及以上用 Display，其余用 Text）加 Microsoft YaHei UI。数字一律 `tabular-nums`。

| 样式 | 字号/行高 | 字重 |
| --- | --- | --- |
| 关键数字 | 30/36 | 600 |
| 页标题 | 28/36 | 600 |
| 区标题 | 20/28 | 600 |
| 卡片标题 | 16/22 | 600 |
| 正文 | 14/20 | 400 |
| 表格 | 13/18 | 400 |
| 说明 | 12/16 | 400 |

### 1.4 间距、尺寸、圆角、层级

- 间距刻度：4、8、12、16、20、28。页边距 28，卡片内边距 22，卡片间距 14。
- 表格行高 38，控件高 32，侧栏项高 38，侧栏宽 212（紧凑档 64）。
- 圆角：控件 6，卡片 8，弹窗 12。
- 层级三级：页面底、卡片面（1px 描边，无阴影）、次级面。

### 1.5 交互与动效

- **图表**：悬停显示十字准线和数值提示；线端直接标注序列名，不用图例。
- **行**：悬停用次级面；可点的行整行可点，点击打开明细或跳转。
- **键盘**：Esc 关闭弹窗或检查器；↑↓ 在表格中移动选中行，检查器内容随之更新；所有控件可用 Tab 到达，焦点环用强调色。
- **动效**：过渡不超过 150 ms，系统开启「减少动画」时关闭。
- 选区拖动、图表缩放、快捷键表：待定。

### 1.6 图表实现

继续手写 React SVG，只引入 d3 的辅助模块：`d3-hierarchy`（方框图布局）、`d3-scale`、`d3-shape`。不引入完整图表库。

## 2. 导航与页面结构

### 2.1 页面

六页分两组，组间加分隔。顺序按问题从粗到细。

| 组 | 页面 | 回答 |
| --- | --- | --- |
| 分析 | 总览 | 有多少钱，今天和这段时间变了多少 |
| 分析 | 收益复盘 | 赚得好不好，比指数如何，谁贡献谁拖累 |
| 分析 | 配置分析 | 钱分在哪，是否集中，离目标多远 |
| 分析 | 持仓 | 每只证券的明细，补数据 |
| 维护 | 导入与对账 | 同步、导入、核对、更正 |
| 维护 | 设置 | 券商连接、账本、数据 |

另有欢迎页（不显示应用外壳）。「策略复盘」改名「收益复盘」，「数据与设置」改名「设置」。

### 2.2 侧栏

左侧栏，浅色，有品牌标记和每项图标。选中项是一块卡片面色的白卡。底部是账本切换和欢迎页入口；示例账本时常驻「示例」标记，窄栏下也可见。

### 2.3 全局筛选

| 筛选 | 范围 | 位置 | 默认 | 重启后 |
| --- | --- | --- | --- | --- |
| 账户范围 | 四个分析页共用 | 页头右侧 | 全部账户 | 记住 |
| 估值日 | 四个分析页共用 | 页头右侧 | 今天 | 回到今天 |
| 期间 | 总览与收益复盘共用 | 页内，贴着它控制的数字和主图 | 今年以来 | 记住 |

- 维护组两页的页头不显示筛选。
- **估值日**默认今天且不显眼。改为过去某天时，页头出现醒目的「正在查看 YYYY-MM-DD」和一键回到今天；此时「今日变动」显示该日的当日变动。
- **期间**预设：本月、近 3 个月、今年以来、近一年、全部。终点都是估值日。
  - 近一年 = 估值日的上一年同日次日至估值日（365 或 366 天），因此总能显示年化。历史不足时区间缩短，年化随之隐藏。
  - 自定义区间只在收益复盘输入。切到总览时五个预设都不选中，旁边显示「起 至 止 ✕」，点任一预设或 ✕ 回到预设。估值日改早后，自定义终点截到估值日；起点也晚于估值日时回到今年以来。
- 持仓和配置分析是时点数据，不显示期间。
- 每次启动进总览。切换账本时三项筛选回到默认。

### 2.4 页间跳转

总览前 5 大持仓的「查看全部」和证券行、收益复盘的贡献行、配置分析的证券行与方框、目标偏离「个股」展开后的代码，都跳到持仓页，定位到该证券并打开它的明细（宽屏档进检查器，其余档弹窗）。全局筛选不变。不设返回按钮。

## 3. 自适应布局

目标视口 1280×720 至 3440×1440，只看 CSS 像素（1920×1080 在 150% 缩放下最大化视口约 1280×649，高度最紧）。超宽屏加列，不拉伸。

### 3.1 档位

按视口宽度分三档。档位只管外壳。

| 档位 | 视口宽度 | 侧栏 | 页头 | 明细 |
| --- | --- | --- | --- | --- |
| 紧凑 | < 1320 | 64 宽图标栏，悬停显示页名 | 高 52，标题 20/28 | 弹窗 |
| 常规 | 1320 – 1799 | 212，图标加文字 | 高 76，标题 28/36 | 弹窗 |
| 宽屏 | ≥ 1800 | 212 | 同常规 | 右侧停靠检查器 |

- 不设高度档位。视口高度低于 720 时，页头用矮版，卡片内边距 22 降为 16。
- 页头固定在顶部，内容区自己滚动。内容区不设最大宽度。

### 3.2 内容栅格

列数跟**内容区宽度**走，不跟视口走；检查器打开、侧栏收起都会改变列数。面板内部用容器查询自适应。

| 内容区宽度 | 列数 | 列宽比 |
| --- | --- | --- |
| < 1480 | 1 | — |
| 1480 – 2239 | 2 | 2 : 1 |
| ≥ 2240 | 3 | 2 : 1 : 1 |

面板内部：关键数字一行 4 个，所在列窄于 900 时排成 2×2；并排的两块在列窄于 760 时上下堆叠；表格在列窄于 700 时隐藏次要列。

### 3.3 主图高度

主图填满首屏剩余高度，下限 240，上限 560（配置分析的方框图为 320 到 700）。内容区高度不低于 800 时，给同列下一块面板留出露出位置。宽度随所在列。

### 3.4 检查器与弹窗

- 检查器只在宽屏档停靠，宽 `clamp(380px, 26vw, 520px)`。**选中才出现**，✕ 关闭并把宽度还给内容区。紧凑和常规档同样内容用弹窗。
- **规则：对着页面看的明细进检查器，表单和确认用弹窗。**
  - 进检查器：证券明细、总资产明细、公司来源拆分、核对／更正流水。
  - 各档都用弹窗：补持仓、设置目标、导入文件、手工补录、结单、备份、恢复、重置、断开连接。

### 3.5 窗口

- 最小窗口 1024×640（视口约 1008×601）。
- 首次启动 1440×900，限制在工作区内。之后恢复上次的位置、大小和最大化状态；那块显示器不在了就回到默认。

## 4. 页面

各页三档布局中，「主列」指 2 : 1 或 2 : 1 : 1 中最宽的一列。

### 4.1 总览

**回答四问**，不点任何东西即可得到答案：

| 问题 | 数字 |
| --- | --- |
| 我现在有多少钱 | 总资产 |
| 今天变了多少 | 今日变动，金额加百分比 |
| 这段时间赚了还是亏了 | 期间投资盈亏、时间加权收益率 |
| 钱是存进去的还是赚来的 | 期间净投入、投资盈亏 |

**内容**（自上而下）：

1. 期间选择。
2. 四张数字卡：**总资产**（品牌绿主卡，附今日变动，点开进总资产明细）、**期间投资盈亏**（附期初资产）、**时间加权收益率**、**期间净投入**（附累计净投入）。
3. **主图：资产走势**。总资产折线加阶梯状净投入线，两线之间按盈亏正负着色；可切到投资盈亏图。
4. **盈亏构成**：一行五项，未实现变动、已实现、分红与利息、费用、汇率，合计等于期间投资盈亏。
5. **前 5 大持仓**：市值、占比、今日涨跌，带「查看全部」。
6. **账户**：每账户一行，总值和今日变动。

**三档**：

| 列数 | 编排 |
| --- | --- |
| 1 | 数字卡 → 主图 → 盈亏构成 →（前 5 大持仓｜账户 并排） |
| 2 | 主列：数字卡、主图、盈亏构成；右列：前 5 大持仓、账户 |
| 3 | 主列：数字卡、主图；中列：前 5 大持仓；右列：账户、盈亏构成 |

**不放**：全部证券整表、待核对事项、数据提示、单列的「持仓账面盈亏」、公司方框图。

### 4.2 收益复盘

| 问题 | 数字 |
| --- | --- |
| 我跑赢指数了吗，差多少 | 时间加权收益率、对每个指数的收益差 |
| 最坏的时候跌了多少 | 最大回撤及起止日期 |
| 谁在帮我、谁在拖累 | 持仓贡献，按金额排序 |
| 落后发生在什么时候 | 最长跑输区间 |

**内容**：

1. 期间选择（含自定义区间）。
2. 四张结论卡：**时间加权收益率**（附年化，区间满 365 天才显示）、**对所选基准的收益差**（附指数收益）、**最大回撤**（附起止日期）、**最长跑输**（附起止日期）。
3. **主图**，分段控件切换三种视图：
   - 累计收益：组合与各基准的归零折线，线端标注。组合用粗实线和序列第 1 位。
   - 收益差：组合减所选基准。
   - 回撤：区间不足 3 个月时不提供此视图，回撤只给数字和日期。
   
   基准用图上方的标签选择（标普 500、纳斯达克 100）。
4. **盈亏构成**五项，可下钻到证券。同一期间下与总览数字一致。
5. **持仓贡献**：排序的正负横条；证券多时折叠中间部分；点行跳到持仓页。瀑布图只用于组合层面的 3 到 5 步。
6. **口径说明**，放在最后。逐日表格和数据来源面板折叠；复盘笔记留在页尾。

**三档**：

| 列数 | 编排 |
| --- | --- |
| 1 | 结论卡 → 主图 → 盈亏构成 → 持仓贡献 → 口径说明 |
| 2 | 主列：结论卡、主图、盈亏构成；右列：持仓贡献、口径说明 |
| 3 | 主列：结论卡、主图；中列：持仓贡献；右列：盈亏构成、口径说明 |

证券贡献含可归属该证券的分红，并扣除对应的交易费用。现金利息等账户收支单列。来源无法确认的收支显示为「待归属」，可点开原始流水。[复盘决定](adr/0003-portfolio-review-contributions.md)

### 4.3 配置分析

| 问题 | 数字 |
| --- | --- |
| 钱分在哪 | 证券权重，含现金占比 |
| 是否太集中 | 最大单一公司敞口、前五大公司合计（穿透 ETF 后） |
| 离目标差多少 | 最大偏离项及偏离百分点 |
| 要调多少 | 回到目标所需的买卖金额 |

**主图：公司敞口方框图**

- 每家公司一个方框，面积为其占总资产的比例（直接持有加 ETF 穿透，同一发行人的股份类别合并）。按行业分组，组上方写行业名和合计。
- 方框内写代码、占比、今日涨跌；字号随方框变化，放不下就不显示。
- 着色可切换：今日涨跌（绿涨红跌，幅度越大越深）、持有方式（直接／经 ETF）。
- 未逐家列出的公司合并成每个行业末端的浅灰块。尚未取得成分的基金另列为「成分待更新」，保留基金金额。
- 可切换为降序条形图。
- 卡片顶部三个数字：最大单一公司、前五大公司合计、逐家列出的家数。
- 点方框打开公司来源拆分（直接持有多少，经哪只 ETF 持有多少），可跳到持仓页。

**目标偏离**

- 目标只设到：每只 ETF 各一项、全部个股合成「个股」一项、现金一项。不逐只个股设目标。
- 每项一行子弹图：实际、目标线、允许偏离带。下面写偏离多少个百分点，以及要买入或卖出多少；在允许范围内写「不用调」。
- **允许偏离**沿用现有再平衡设置：一个由用户设定的统一范围，以百分点计，默认 ±5，可设 0.5 到 25。
- 「个股」行可展开看包含哪几只。
- 「设置目标」弹窗只有这几项的输入框和允许偏离，合计必须等于 100% 才能保存。
- 两种占比均以所选账户含现金的总资产为分母。目标绑定设置时的账户范围；单看某账户时，偏离只按当前范围已设的目标计算。

**其他分布**：行业、国家、资产类别、账户、币种，用降序条形图，折叠在最后。

**三档**：

| 列数 | 编排 |
| --- | --- |
| 1 | 方框图 → 目标偏离 → 其他分布 |
| 2 | 主列：方框图、其他分布；右列：目标偏离 |
| 3 | 方框图、目标偏离、其他分布各占一列 |

### 4.4 持仓

每只证券回答：我有多少、成本多少、现在值多少、赚亏多少、今天涨跌多少。

**内容**：

- 顶部工具栏：搜索、按类别筛选、「补持仓」。下面一行合计（不再有四个数字块）。
- 每个账户一张卡，卡头写账户名、证券只数和市值。卡内是持仓表，按市值降序，末行是现金。
- 每行：股数、成本、市值、未实现盈亏及盈亏率、今日涨跌（金额与「涨跌幅」）、累计已实现盈亏、累计分红。金额以 AUD 列示。
- 点行打开证券明细（宽屏档检查器，其余档弹窗）：各账户分别持有多少，交易币种下的现价与买入均价（如美股两项均标 USD），补成本、补报价入口。
- 从其他页跳来时定位到该证券并打开明细。
- 缺成本的证券，成本和盈亏显示待补，可在明细里直接补。从持仓补数据时预填账户、证券和估值日；保存后回到原行，保留筛选、排序和滚动位置。

**三档**：1、2 列时账户卡单列依次排；3 列时账户卡分两栏。

### 4.5 导入与对账

流程不变，只改视觉、排版和自适应。

- 页内四个页签：**记录与同步**、**和券商结单核对**、**交易流水**、**从这一天开始记录**。除第一个外，页签行右侧有账户选择。
- 记录与同步：导入卡加导入预览；未同步时显示导入卡和历史批次。宽屏最多三列并排。
- 和券商结单核对：结单与凭证两张卡，窄时上下排，宽时并排。
- 交易流水：表格，不限宽。核对／更正流水在宽屏档进检查器。
- 宽度：表单限宽 760，表单卡片限宽 880，表格不限宽。

流程要点：

1. **导入券商文件**。IBKR 导入 Activity Flex XML，读取成交、资金活动、现金余额和持仓。Webull Australia 导入成交 CSV，现金余额和资金流水通过月结单核对并补录。[IBKR Flex 文件格式](https://www.ibkrguides.com/clientportal/performanceandstatements/activityflex.htm) · [Webull 成交导出](https://www.webull.com.au/learn/courseware/G4QpCp/Feature-Update-Trade-Record-CSV-Export)
2. **预览并确认**。按券商分别预览，只列新增记录和字段级变化，用券商记录 ID 去重。一家同步失败时可先确认另一家，再单独重试。确认后按批次写入，保留来源和更正记录。
3. **建立计算起点**。历史不全时从一份结单登记期初余额：每只证券数量、各币种现金和日期。
4. **核对同日数据**。按账户核对证券数量和各币种现金，再比较同一时点、同一汇率口径的资产总值。差异写出账户、证券和相差股数，例如「Webull 的 IVV 比结单少 2 股」。
5. **手工补录**：「补一笔买卖」、「补持仓」（成本可留为未知）、「补报价」。补录的某日股数可与后来取得的成交核对。[股数核对决定](adr/0004-reconcile-dated-security-quantities.md)

### 4.6 设置

- 页内三个页签：**券商连接**、**账本**、**数据**。每个页签下若干卡片，窄时单列，宽时最多两列（合计 1760）。
- 券商连接显示连接状态、上次成功时间和「立即更新」；需要授权时展开对应步骤。
- 一个来源记录有多个上市证券候选时，用全名、市场和币种列出选项；确认后记住对应关系。
- 备份、恢复、重置、断开连接用弹窗确认。

### 4.7 欢迎页

套用设计系统，不显示应用外壳。两张卡片沿用现有内容：正式账本（打开或迁入）、示例组合。窄时上下排，宽时并排。

## 5. 指标与口径

完整口径见 [ADR 0002](adr/0002-portfolio-benchmark-returns.md)、[ADR 0003](adr/0003-portfolio-review-contributions.md)、[ADR 0005](adr/0005-gain-breakdown-and-daily-change.md)。

| 指标 | 出现在 | 口径 |
| --- | --- | --- |
| 总资产 | 总览、持仓 | 证券市值加账户现金，按估值日报价和汇率折 AUD |
| 今日变动 | 总览、账户行 | 净值口径：最近可估值收盘日估值 − 前一可估值收盘日估值 − 当日净外部资金流，标注日期。百分比为当日时间加权收益。含汇率、分红、利息、费用 |
| 今日涨跌（证券行） | 总览前 5、持仓、方框图 | 金额同净值口径，可加总到组合；「涨跌幅」用交易币种的价格涨跌幅 |
| 期间投资盈亏 | 总览、复盘 | 期末估值 − 期初估值 − 期间净外部资金流。选中账户间已匹配的转账是内部划转 |
| 期间净投入 / 累计净投入 | 总览 | 期间 / 有记录以来的净外部资金流 |
| 时间加权收益率 | 总览、复盘 | ADR 0002，全应用只用这一个收益率，两页同一个数 |
| 年化收益 | 复盘 | `(1+R)^(365/天数) − 1`，区间满 365 天才显示；指数同公式并列，不展示年化之差 |
| 收益差 | 复盘 | 组合时间加权收益率减指数收益率 |
| 最大回撤、最长跑输 | 复盘 | 区间内峰谷跌幅及起止日；组合持续落后所选基准的最长区间 |
| 盈亏构成五项 | 总览、复盘 | 未实现变动、已实现（平均成本法，卖出日汇率）、分红与利息（税后净额，到账日）、费用（全部费用）、汇率（余数）。五项之和恒等于期间投资盈亏 |
| 持仓贡献 | 复盘 | ADR 0003 |
| 累计已实现、累计分红 | 持仓 | 从账户有记录起累计，含期初余额带入的持仓；无成本凭据的转入证券不计已实现 |
| 持仓账面盈亏 | 持仓 | 交易币种内计算，成本含买入费用，按估值日同一汇率折 AUD |
| 集中度 | 配置分析 | 最大单一公司、前五大合计；分母为所选账户总资产（含现金）；只排公司行，穿透残余、现金、债券不排名但留在分母 |
| 目标偏离、调仓金额 | 配置分析 | 实际占比 − 目标占比（百分点）；金额 = −偏离 × 总资产 |

**删除**：现有的「收益率 = 盈亏 ÷（期初估值 + 全部流入）」不再显示。资金加权收益率不做。

### 5.1 数据缺口

界面不提示缺报价、缺汇率、无法识别的流水或券商快照与本地不一致。这些按缺陷处理，由应用修复。

- 缺报价或汇率时，取估值日当日或之前最近一个已知值。
- 某证券从未取得报价或汇率时如何取值：待定。

## 6. 验收场景

- 同一证券在 IBKR 持有 8 股、在 Webull 持有 2 股。持仓页两张账户卡各列一行；证券明细显示合计 10 股及各账户股数。总览前 5 大持仓按合计市值排一行。
- 总览切换「近 1 月」和「今年以来」，总资产和前 5 大持仓不变；期间投资盈亏、收益率、净投入、主图和盈亏构成随之变化。切到收益复盘，同一期间的收益率和盈亏构成与总览一致。
- 估值日改为 2025-12-31：页头出现「正在查看 2025-12-31」；今年以来为 2025-01-01 至 2025-12-31；近一年为 2025-01-01 至 2025-12-31，复盘显示年化。
- 区间不足 3 个月时，复盘主图没有回撤视图，最大回撤卡仍有数字和日期。
- 某证券一股以 A$40 买入，期初市值 A$100，期内以 A$110 卖清，无费用和分红。盈亏构成：已实现 +70、未实现变动 −60；复盘贡献列出「+A$10 · 期间已卖清」。
- 区间内 IVV 价格变动贡献 +A$100，可归属分红 +A$8，交易费 A$2，账户另有现金利息 +A$3。复盘显示「IVV +A$106」和「现金利息 +A$3」。
- 两个账户间划转 A$1,000，报价、汇率不变且无费用：全部账户的净投入和盈亏均为零；只看收款账户时净投入 A$1,000、盈亏为零。
- 某证券只有 10 股和当日报价，缺成本。持仓行显示市值，成本和盈亏待补；明细里补成本后回到原行，筛选和滚动位置保留。
- 所选账户共 A$100,000，IVV 市值 A$40,000，现金 A$20,000，IVV 目标 45%，允许偏离 ±5。配置分析显示 IVV 低 5 个百分点、「不用调」。目标改为 46% 后显示「买入 A$6,000」。
- 直接持有苹果占 4%，经 IVV 持有占 3%。方框图中苹果占 7%；点开来源拆分列出两条来源，宽屏档在检查器中打开。
- 在 1920 宽窗口点持仓行，检查器停靠右侧，内容区从两列变为一列；✕ 关闭后恢复两列。在 1280 宽窗口同一操作弹出弹窗。
- 从配置分析点「个股」下的代码，跳到持仓页并打开该证券明细，账户范围和估值日不变。
- IBKR 有 6 条待确认而 Webull 同步失败时，可确认 IBKR 的 6 条，再单独重试 Webull。
- 重复导入同一文件，账户持仓和现金不变。
- 1024×640 窗口下侧栏为 64 图标栏，页头为矮版，总览单列，主图高 240。
- 关闭时窗口最大化在副屏；拔掉副屏后启动，窗口以 1440×900 出现在主屏。
