# Stock Portfolio 独立投资管理应用设计

Stock Portfolio 是一款独立运行的个人投资看板。首版按单用户 Windows 桌面应用设计，使用本机 SQLite 账本，以 AUD 汇总 IBKR 和 Webull Australia 账户。导入、估值和看板都由应用自行处理，离线可查看已保存的数据和估值日期。

打开首页后，30 秒内看懂选中账户一共有多少钱、资金分布在哪里、最近赚亏多少，以及哪些数据需要核对。

## 首页布局

| 区域 | 显示内容 | 可执行操作 |
| --- | --- | --- |
| 顶部 | 账户范围、显示币种、估值日期和数据状态 | 在全部账户、IBKR、Webull 或自选组合之间切换 |
| 首屏数字 | 总资产、证券市值、账户现金、所选期间投资盈亏 | 展开金额口径和来源 |
| 资产走势 | 实际总资产与「期初资产＋累计净投入」两条线，图旁显示该期间净入金 | 切换近 1 月、近 3 月、今年至今或已覆盖的全部历史 |
| 资产分布 | 按账户列出金额与占比，按市值显示前五大持仓 | 点账户查看持仓和现金，点证券查看来源和报价时间 |
| 待核对事项 | 影响当前数字的缺失报价、汇率或券商记录，标出受影响账户和指标 | 查看明细和最近一次有效数据 |

> **首页示例（虚构数据）**　总资产 A$128,400 · 证券 A$114,800 · 现金 A$13,600
>
> **近 1 月**　资产总值增加 A$4,200，其中净入金 A$1,000，投资盈亏 +A$3,200。

主导航为「总览」「持仓」「导入与对账」。账户筛选影响整张看板。期间筛选影响走势、净入金和盈亏，当前持仓按估值日期显示。后续在「持仓」增加配置视图，可按证券查看目标偏离，按公司查看直接持股和各 ETF 的贡献。

## 导入与对账

1. **导入券商文件。** IBKR 导入 Activity Flex XML，读取成交、资金活动、现金余额和持仓。Webull Australia 导入成交 CSV，现金余额和资金流水通过月结单核对并补录，具体可自动导入的字段以样本为准。[IBKR Flex 文件格式](https://www.ibkrguides.com/clientportal/performanceandstatements/activityflex.htm) · [Webull 成交导出和结单格式](https://www.webull.com.au/learn/courseware/G4QpCp/Feature-Update-Trade-Record-CSV-Export) · [Webull 成交导出范围](https://www.webull.com.au/help/faq/1762)
2. **预览并确认。** 文件映射到本地账户，列出新增、重复、冲突和未识别记录。用券商记录 ID 识别重复。无可靠 ID 的相似记录保留待核对状态。确认后按批次写入，保留来源和更正记录。
3. **建立计算起点。** 历史不全时，从一份券商结单建立期初余额，记录每只证券数量、各币种现金和估值日期。时间线从可核对的日期开始，已有持仓和现金作为期初资产。
4. **核对同日数据。** 按账户核对证券数量和各币种现金，再比较同一时点、同一汇率口径的资产总值。点差异可查看关联流水、报价和汇率。差异留待核对，账本更正以原始记录为依据。

## 金额和数据口径

- **总资产**等于证券市值加账户现金。总览按 AUD 汇总，持仓明细同时显示原币。每份估值记录估值日期、所用报价和汇率。过期报价标明日期，缺报价或汇率时显示已估值小计和缺失项。
- **期间投资盈亏**等于期末估值减期初估值，再减期间净外部资金流。选中账户之间已匹配的转账属于内部划转。只选中转账一侧时，该笔划转计入该范围的外部资金流。股息、利息、手续费和持仓的汇率变动反映在盈亏中。
- **盈亏可用性**取决于期初和期末估值，以及区间资金流能否核对。缺失项只影响相关账户、期间和指标。首版先交付盈亏金额，收益率在估值与资金流可以验证后再加入。

## 第一版范围

先打通股票、ETF 和 AUD／USD 现金的历史导入、估值、对账与看板。账本保存账户、期初余额、交易和资金流水，行情和汇率单独保存并按估值日期读取。应用提供本地备份及恢复。可复用现有 IBKR 文件解析和与宿主无关的配置、穿透计算，桌面应用直接读取自己的账本。

正式 Windows 版包含原 Allocation 和 Broker Sync 的功能。配置分析支持公司及多层 ETF 穿透、贡献来源、行业和国家分布、目标权重与允许偏离，以及 ETF 成分维护。券商同步保留按需连接、预览、去重、更正和结单核对。数据迁移承接旧账本及设置，迁入后由 Stock Portfolio 独立维护。[账本归属决定](adr/0001-independent-portfolio-ledger.md)

## 验收场景

- 在未安装 Wealthfolio 的电脑上启动应用，导入券商文件后生成看板。重复导入同一文件，账户持仓和现金保持一致。
- 两个账户间划转 A$1,000。在无费用且报价、汇率不变的测试期间，组合的净外部资金流及盈亏均为零。只看收款账户时显示 A$1,000 净流入，盈亏仍为零。
- Webull 只有成交 CSV 时，能查看已导入的成交，首页标明现金余额和盈亏所缺的字段。补齐结单及流水并对账后，更新相应指标。
